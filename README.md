# Python Internship Projects

Python internship projects by **K. Yashwanth**: a To-Do List, a Calculator, and a Rock-Paper-Scissors Game. All three run in the terminal and use only Python's standard library, so there is nothing extra to install.

## Projects

| Task | Project | File |
|------|---------|------|
| 1 | To-Do List | `task1_todo_list.py` |
| 2 | Calculator | `task2_calculator.py` |
| 4 | Rock-Paper-Scissors Game | `task4_rock_paper_scissors.py` |

### Task 1: To-Do List
A command-line app to manage daily tasks.
- Add, view, update, mark as done, and delete tasks
- Tasks are saved to `tasks.json`, so they stay after you close the program

### Task 2: Calculator
A simple calculator for basic arithmetic.
- Takes two numbers and an operation (`+`, `-`, `*`, `/`)
- Handles invalid input and division by zero
- Lets you do another calculation without restarting

### Task 4: Rock-Paper-Scissors Game
Play against the computer.
- The computer picks randomly; the winner is decided by the standard rules
- Shows both choices and the result of each round
- Tracks your score, the computer's score, and ties
- Asks if you want to play again and shows the final result

## How to Run

1. Install [Python 3](https://www.python.org/downloads/).
2. Download or clone this repository.
3. Open a terminal in the project folder and run any project:

```bash
python task1_todo_list.py
python task2_calculator.py
python task4_rock_paper_scissors.py
```

## Concepts Used
- Functions, loops, and conditional statements
- Input validation and error handling (`try` / `except`)
- File handling with JSON
- Random module and game logic
